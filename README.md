# 🚒 불조심 배틀 119 (Fire Battle 119)
> **불조심 어린이마당 대비 학급 전용 실시간 30인 퀴즈 배틀 플랫폼**

교재 **『불조심 길라잡이』(초등학생용 128p)** 전체 내용을 완벽히 반영하여, 초등학교 4학년 학생들이 교실에서 30명 동시 접속하여 실시간 순위 변동과 아이템 난투를 즐길 수 있는 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 가이드 (실행 방법)

### 1. 패키지 설치
```bash
npm install
npm --prefix server install
npm --prefix client install
```

### 2. 서버 및 클라이언트 동시 실행
```bash
npm run dev
```

* **대형 스크린 / 전자칠판 (호스트):** 브라우저에서 `http://localhost:5173` 접속 후 **[교실 대형 스크린 / 전자칠판용 새 방 만들기]** 클릭
* **학생 접속 (스마트폰 / 태블릿):** 각 기기 브라우저에서 `http://localhost:5173` 접속 후 호스트 화면의 **6자리 PIN 번호**와 **이름**, **소방 아바타**를 선택하고 입장

---

## ✨ 핵심 기능

1. **30인 동시 접속 & 가상 친구 AI 봇 지원:**
   * 혼자 테스트할 때도 호스트 화면의 **[우리 반 친구 30명 채우기]** 버튼을 누르면 29명의 가상 반 친구 봇이 자동 입장하여 실제 30명 풀방 배틀을 그대로 체험할 수 있습니다.
2. **『불조심 길라잡이』 핵심 25문항 수록:**
   * 불의 3요소, 화재 원인 통계(부주의 46.5%), 대피 요령(젖은 수건, Stop-Drop-Roll), 응급처치(CPR 30:2, AED, 하임리히법), 소방/피난 시설(K급 소화기, 완강기, 방화문), 승강기 고유번호 등
3. **0.1초 단위 실시간 순위 변동 (사다리 추월 시스템):**
   * 답안 제출 속도(밀리초 단위)에 따른 스피드 보너스(최대 500점) 및 연속 정답 콤보/피버 모드 반영
4. **승부욕을 자극하는 아이템전:**
   * 연막탄(상대 화면 가리기), 소화수(타이머 감소), 사이렌(보기 순서 섞기), 쉴드(방어)
5. **무지연 Web Audio 효과음:**
   * 심장 박동, 사이렌, 딩동댕, 폭죽 등 몰입도 높은 사운드 내장
