# 🚒 불조심 배틀 119 (Fire Battle 119)
> **불조심 어린이마당 대비 학급 전용 실시간 30인 퀴즈 배틀 플랫폼**

교재 **『불조심 길라잡이』(초등학생용 128p)** 전체 내용을 완벽히 반영하여, 초등학교 4학년 학생들이 교실에서 30명 동시 접속하여 실시간 순위 변동과 아이템 난투를 즐길 수 있는 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 가이드 (실행 방법)

### 1. 패키지 설치
```bash
npm install
npm --prefix server install
npm --prefix client install
```

### 2. 서버 및 클라이언트 동시 실행
```bash
npm run dev
```

* **대형 스크린 / 전자칠판 (호스트):** 브라우저에서 `http://localhost:5173` 접속 후 **[교실 대형 스크린 / 전자칠판용 새 방 만들기]** 클릭
* **학생 접속 (스마트폰 / 태블릿):** 각 기기 브라우저에서 `http://localhost:5173` 접속 후 호스트 화면의 **6자리 PIN 번호**와 **이름**, **소방 아바타**를 선택하고 입장

### 배포 구조

- **Vercel:** `client`의 HTML, JavaScript, CSS, WebP 정적 파일
- **Render:** `server`의 Socket.IO 게임 서버와 상태 데이터만 처리

Vercel 프로젝트에는 `VITE_SOCKET_URL=https://<Render 서비스 주소>`를 설정합니다. Render 서비스에는 `CLIENT_ORIGINS=https://<Vercel 운영 주소>`를 설정합니다. 여러 주소를 허용할 때는 쉼표로 구분합니다.

루트의 `vercel.json`과 `render.yaml`에 각각의 빌드 설정이 준비되어 있습니다. 배포 후 사용자는 Vercel 주소로 접속하며, Render 주소는 게임 연결과 `/api/health` 확인에만 사용합니다.

### 네트워크 최적화

- 변경되지 않는 닉네임, 아바타, 차량 정보는 레이스 시작 시 한 번만 전송
- 게임 중에는 점수, 진행도, 순위 같은 동적 정보만 1초마다 동기화
- WebSocket 메시지 압축 적용
- 중복 시작 요청과 재경기 시 순위 타이머 누수 차단

## ✨ 핵심 기능

1. **30인 동시 접속 & 가상 친구 AI 봇 지원:**
   * 혼자 테스트할 때도 호스트 화면의 **[우리 반 친구 30명 채우기]** 버튼을 누르면 29명의 가상 반 친구 봇이 자동 입장하여 실제 30명 풀방 배틀을 그대로 체험할 수 있습니다.
2. **2026년 『불조심 길라잡이』 기반 신규 500문항 수록:**
   * 4지선다형 객관식 400문항과 직접 입력하는 단답형 100문항
   * 100개 핵심 개념별 5가지 변형을 제공하되, 한 게임에서는 개념당 1문항만 출제해 중복 학습 방지
   * 재경기할 때는 각 개념의 다음 변형으로 순환하여 같은 문제 형식 반복 방지
   * 불의 원리, 2021~2025년 화재 통계, 대피, 응급처치, 소방·피난시설, 자연재난, 아파트·승강기·캠핑 특별편까지 교재 전 범위 반영
3. **0.1초 단위 실시간 순위 변동 (사다리 추월 시스템):**
   * 답안 제출 속도(밀리초 단위)에 따른 스피드 보너스(최대 500점) 및 연속 정답 콤보/피버 모드 반영
4. **승부욕을 자극하는 아이템전:**
   * 연막탄(상대 화면 가리기), 소화수(타이머 감소), 사이렌(보기 순서 섞기), 쉴드(방어)
5. **무지연 Web Audio 효과음:**
   * 심장 박동, 사이렌, 딩동댕, 폭죽 등 몰입도 높은 사운드 내장
